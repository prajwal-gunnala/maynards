2. The Physics of Latency: The Dual-Mode Scheduler

In distributed LLM generation, token decoding is strictly sequential: token $t+1$ cannot begin compute until token $t$ finishes traversing all nodes. The per-token decoding latency equation is:

$$T_{\text{token}} = \sum_{i=1}^{N_{\text{nodes}}} T_{\text{compute}, i} + \sum_{k=1}^{N_{\text{hops}}} \text{RTT}_k$$

NEAR MODE: Fine-Grained Pipelining

Condition: USB Cable or LAN RTT $\le 12$ ms

Over USB tethering, physical latency is 2–3 ms. Two network hops add only $\approx 5$ ms of network delay per token. Combined with 135 ms compute time, total token time is $\approx 140$ ms, yielding 6.7 – 7.1 tokens/sec sustained throughput.

FAR MODE: Autonomous Whole-Job Offload

Condition: WAN Relay or Cellular RTT $> 12$ ms

Over 5G mobile data / relay, latency is 40–90 ms. Two network hops would add $180$ ms network latency per token, choking throughput down to $\approx 1.5$ tok/s! In Far Mode, the scheduler refuses to pipeline layers across the WAN; instead, it dispatches whole standalone tasks (e.g., background job queue prompts) autonomously.

4. Warm RAM Economics & Metering Arbitrage

Running LLMs in the cloud is economically dominated by idle GPU RAM reservation. RunPod / AWS charges $\approx \$2.34/\text{GB-month}$ for persistent VRAM regardless of whether inference is actively computing. A smartphone sitting warm on a desk or charger costs only electricity: $\approx \$0.168/\text{GB-month}$.

The Economic Arbitrage Ratio (92.8% Savings)
$$\text{Arbitrage} = 1 - \frac{\$0.168}{\$2.34} = 92.82\% \text{ Cost Reduction}$$ The built-in Meter Ledger (/api/meter) records per-device residency seconds and generated tokens every 2 seconds, persisting cryptographically verified earning shares into meter.jsonl.

5. Cybersecurity: Defending Against Activation Inversion (ActInv)

A common false pitch claim in distributed inference is: "We only send activations, so your data is private."

The ActInv Vulnerability (ACM CCS '26)
Recent peer-reviewed research (ActInv, USENIX/CCS 2026) proves that intermediate activation tensors can be mathematically inverted using pretrained text-decoding heads (vec2text), recovering 92% of input tokens from raw hidden states.

The Mesh Defense: MeshAI guarantees privacy not through mathematical obscurity, but through topological tensor containment:

  • Embedding Layer Pinned: token_embd never leaves the Host device. Raw plaintext tokens are converted to hidden vectors strictly inside local RAM.
  • Output Logit Projection Pinned: output and output_norm remain on the Host. Helper phones never see the vocabulary distribution logits.
  • Helper Blindness: Helper phones only compute middle-layer transformer blocks. Without the tokenizer vocabulary matrix or the input embeddings, inverting intermediate layers over a partial slice is statistically intractable.
